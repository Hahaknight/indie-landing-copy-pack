# Indie Landing Copy Pack

**10 fill-in-the-blank landing page templates for solo builders. Blank page → published page in one sitting.**

🔗 **Read them online: <https://hahaknight.github.io/indie-landing-copy-pack/>**

## Why this exists

Writing landing copy from a blank page is the #1 reason side projects die unpublished. This pack hands you the hard part — the *structure* and the *transitions* — and leaves brackets where your product goes. You fill the blanks, you ship.

What you get, per template:

- a complete headline → subhead → proof → features → pricing → FAQ → CTA flow
- bracketed placeholders showing exactly what kind of sentence belongs where
- copy that assumes a one-person product, not a funded startup (no "enterprise-grade" nonsense)

Works for tools, templates, content sites — anything a solo builder launches.

## Self-host

Single static `index.html`, zero dependencies.

```bash
git clone https://github.com/Hahaknight/indie-landing-copy-pack
# open index.html directly, or enable GitHub Pages on your fork
```
